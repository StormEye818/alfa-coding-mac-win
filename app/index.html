配置项修改

连接车辆并读取配置后，各项将显示当前生效值。勾选需修改的项，工具会自动写入对应字节并重算校验。

⚠ 位冲突

    命名配置项

    按名称配置，每项按位掩码写入，不影响同字节的其它配置位。共 0 项。

    扩展配置项

    未包含在命名配置中的附加项，含多选项时为单选。

    PROXI 字节编辑器

    点击字节可展开位编辑，逐位切换；改动会高亮显示。写入前自动重算校验。虚线格 B7–B11 是 CRC 校验区，改动配置后它们跟着变是正常的（不重算 ECU 会拒收）。

    关于对齐方式（依据诊断协议实现核实）
    • 写入是逐节点独立的：同一份完整配置块（2E 20 23 <DATA1>）逐个发给各节点，每节点独立连接、独立重试、独立校验，无全局提交步骤。因此「只补写失败节点」与「全量重跑」对这些节点的效果等价。
    • 对齐状态以车身电脑 DATA1 / DATA3 位图比对为准：DATA1[25..40] 是 PROXI 配置位图（应该有哪些节点），DATA3[32..47] 是 CAN 实际位图（车上实际有哪些节点）。只在配置里 = 待移除；只在实际里 = 待添加；两者都有 = 已对齐；EOL 位另判。
    • 只有「实际位图」置位的节点才能勾选/写入：待移除（配置里有、车上没有）与未安装节点的复选框是禁用的，写入前还会按位图再核一遍。「全部对齐」= 一次写全部在位节点，与车端全量口径一致。
    • 车端全量写入按 EOL 期望位图取节点（DATA3[48..63]，位为 0 直接跳过）。该位图在部分车上可能全 0（等于不过滤）；若某节点实际在位、EOL 位却没置位（多见于后加装件），写入前会单独弹窗确认，避免与官方口径悄悄分叉。
    • 位图一致 ≠ 每个模块的存储块都一致：位图只反映「配置 ↔ 实际」的节点清单。换过模块（新模块里是旧块、位图却正常）时里程表仍会闪 —— 这种情况执行一次「全部对齐」即可重写全部在位节点，写入结果会逐节点回读。
    • 22 10 2A 只用于单节点写入后的回读校验，不作为整车状态来源。实车部分模块不应答该 DID，读不到不代表未对齐。
    • 兜底：若补写后里程表仍闪烁，请执行一次「全部对齐」（与官方平台一致，一次完成所有已安装节点）。
    • ⚠ 对齐会复位 ABS（Giulia / Stelvio），完成后需做转向角、加速度、胎压标定。
    • ⚠ 一旦开始不要中断。钥匙 ON、发动机 OFF；完成后按提示将钥匙 OFF 至少 60 秒再上电。
