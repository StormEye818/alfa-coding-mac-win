# AlfaProxi 使用教程

面向 Alfa Romeo **Giulia (952)** / **Stelvio (949)** 的刷隐藏、PROXI 对齐与诊断工具。

---

## 一、启动

需要三个进程：

```bash
# 终端 1：串口桥（硬件 I/O 必需）
cd ~/alfaproxi/bridge && node server.js

# 终端 2：测试车辆（模拟 Giulia 全车 ECU，测试时用；连真车则不需要）
cd ~/alfaproxi && node sandbox/harness.mjs
# 打印「连接方式: TCP 127.0.0.1:35001」即就绪

# 终端 3：界面
cd ~/alfaproxi && npm run app
```

打开 `http://localhost:8848/app/`

---

## 二、连接车辆

顶部连接区从左到右：

| 控件 | 说明 |
|---|---|
| **车型** | Giulia (952) / Stelvio (949) |
| **接口类型** | 17 种接口，按 USB / 蓝牙 / WiFi / 串口 / 自动分组 |
| **串口** | 选择适配器所在端口（WiFi 型会变成「IP:端口」） |
| **速率** | 多数 ELM 用 38400，OBDKey 用 9600，ELM327 高速模式 230400 |
| **测试** | 检测所选接口是否正常（识别型号、版本、延迟） |
| **扫描接口** | 逐端口探测并自动识别接口类型 |
| **连接** | 建立连接。**按住 Ctrl 点击**或按 **Ctrl+F10** 进入模拟模式 |
| **模拟** | 不连车，浏览功能与流程 |

**连接流程**：选车型 → 选接口类型 → 选串口 → 点「连接」→ 工具会连上车身电脑并**自动读取车辆配置**。

**测试环境连接**（连测试车辆）：接口类型选任一 **WiFi 型**（如「OBDLink / Vgate vLinker」），地址填 `127.0.0.1:35001`，点「连接」。

读取成功后顶部显示 `已连接：车身电脑（马瑞利，Giulia 952）` 与 `已读取 N 字节`。

> ⚠️ 若提示「需要更换适配线」，请按提示换线后点「已换好，继续」。vLinker MS 支持多路 CAN 自动切换，不会提示；ELM327 在跨总线时会提示。

## 三、配置项修改（刷隐藏）

「配置项修改」页分两部分：

### 3.1 命名配置项（44 项）
按名称配置，每项按位掩码写入，不影响同字节其它位。
- 读取配置后显示**当前生效值**
- 改下拉选项后变**黄色「待写入」**
- 例：`动态驾驶模式选择器（DNA/Race）` → 类型 1 / 类型 2 / 类型 3

### 3.2 扩展配置项（19 项）
带多个选项的为单选，同样有「待写入 / 已写入 / 写入失败」三态。

### 3.3 操作顺序（重要：预览 ≠ 写入车辆）
1. 勾选/选择要改的项（同字节冲突会红字告警）→ 立即变黄「待写入」，右下角浮出「已选 N 项待写入」条
2. （可选）点 **「应用到字节（预览）」** → 只把改动合入字节编辑器供核对，**不写入车辆**
3. 点 **「写入 ECU」**（隐藏功能页 / 字节编辑器页 / 浮动条上都有）→ **真正写入车辆**：自动带上全部所选项、读回校验，成功变绿「已写入」，失败变红「写入失败」
4. 写入成功后才可进行 **PROXI 对齐**（§五）

命名配置项与扩展配置项操作与反馈一致：选中即「待写入」，写入后「✓ 已写入 / ✗ 写入失败」。

> ⚠️ 写入前请点「导出配置备份」保存原值。

## 四、字节编辑器

点击任意字节展开**位编辑面板**：
- 点方块直接翻转该位（bit7 → bit0）
- 可改十六进制值（输入 `EC` 或 `0xEC` 均可）
- 改动标黄，自动重算 CRC
- 「还原此字节」恢复原始值

---

## 五、PROXI 对齐

改完配置后**必须做 PROXI 对齐**，否则车辆不接受改动、里程表会闪烁。

### 5.1 读取对齐状态
点 **「读取对齐状态」** → 逐模块按 `22 10 2A` 回读校验与车身电脑基准比对（0x292E 写入计数仅作辅助参考）：
- `✓ 已对齐` / `⚠ 未对齐` / `✗ 读取失败` / `未安装`
- 顶部结论：`✓ 整车对齐正常，无里程表闪烁` 或 `⚠ 有 N 个模块未对齐 → 里程表会闪烁`
- 未对齐节点会直接报出差异字节；「只选未对齐」可一键选出这些节点补对齐

### 5.2 对齐操作
| 按钮 | 作用 |
|---|---|
| 全选 / 清空 | 选择已安装节点 |
| **只选失败** | 只勾选本次失败的节点 |
| **只选未对齐** | 只勾选状态检查发现未对齐的节点 |
| **全部对齐** | 一次对齐所有已安装节点（与官方平台一致） |
| **对齐所选节点（N）** | 只对齐勾选的节点 |

### 5.3 对齐过程
按 `直连 → 舒适CAN → 底盘CAN` 分组推进，每个节点：
```
⟳ 正在对齐 3/30 · 制动系统 ABS / ESP（大陆 MK C1）
✓ 3/30 · 制动系统 ABS / ESP 对齐成功
```
写入后按节点读 `22 10 2A` 校验，直接报告差异字节。最后给汇总，失败节点可单独重试。

> ⚠️ 对齐会复位 ABS（Giulia/Stelvio），完成后需做转向角、加速度、胎压标定。
> ⚠️ 一旦开始不要中断。钥匙 ON、发动机 OFF。

## 六、特殊功能（539 项）

按分类/模块/安全等级筛选，可搜索。执行前对话框显示：
- **下拉选择**：固定可选值（如胎压参考值 2.00 bar / 29 psi …）
- **数值输入**：单位、取值范围、步进（如保养周期 km，0~127500，步进 500）
- **日期**（十六进制输入按数据定义支持，当前数据集暂无此类条目）
- **红色安全警告**（刹车排气、电子手刹、雷达标定、钥匙编程等）

分段执行状态：`连接模块中 → 已连接 → 执行中 → 完成`。

安全等级：`离线可用` / `需 PIN` / `需服务器密钥·不支持`（后者的按钮禁用）。

## 九、验证刷写是否成功的标准

1. **写入后读回一致**：写入 ECU 后工具显示「读回校验一致」，字节编辑器里改动项变绿「已写入」
2. **PROXI 对齐成功**：「读取对齐状态」显示全部已安装节点 `✓ 已对齐`，结论为「整车对齐正常，无里程表闪烁」
3. **配置项当前值正确**：重新读取后，各项显示的当前值应等于设定值
4. **无里程表闪烁**：对齐完成后结论区显示无闪烁

> 若出现「未对齐」或结论提示闪烁，请点「只选未对齐」→「对齐所选节点」补对齐；仍不行则点「全部对齐」。
